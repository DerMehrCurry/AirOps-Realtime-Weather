# Migration: v0.7.2.4 to v0.7.2.5

Version v0.7.2.5 is a drop-in validation hotfix and includes the complete timezone correction from v0.7.2.4.

## Required steps

1. Replace the complete `airops_weather` resource directory.
2. Keep your existing `config.lua` if it contains custom settings.
3. Restart the resource with `restart airops_weather`.
4. Run `airops_weather_selftest` and confirm that all checks pass.

No database, API, SDK or configuration migration is required.
