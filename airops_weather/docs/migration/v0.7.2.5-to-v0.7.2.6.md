# Migration: v0.7.2.5 to v0.7.2.6

No mandatory configuration migration is required.

AirOps is now the default authoritative weather controller. The default value of
`Config.Integrations.naturalDisasters.delegateWeather` changed from `true` to
`false` to prevent competing client weather synchronizers.

To delegate baseline weather to `night_natural_disasters`, explicitly set the
option back to `true`. In that mode the external resource is responsible for
consistent weather synchronization for every client.

`Config.Weather.strictSynchronization` is enabled by default. Set it to `false`
only when soft client-side transitions are preferred over immediate convergence.
