# Migration: v0.7.2.1 to v0.7.2.2

Version v0.7.2.2 replaces the individual server entries in `fxmanifest.lua` with `server/bootstrap.lua`.

The bootstrap loads all server modules into a single shared Lua environment. This prevents namespace members such as `AirOpsWeather.Providers` and `AirOpsWeather.Validation` from becoming unavailable between module files.

No configuration, database, API or SDK migration is required. Replace the complete resource directory and restart it. Do not copy only `fxmanifest.lua`; the new `server/bootstrap.lua` file is required.
