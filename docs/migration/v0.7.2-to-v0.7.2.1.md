# Migration: v0.7.2 to v0.7.2.1

Version v0.7.2.1 is a drop-in startup hotfix.

## Required steps

1. Replace the existing resource files with v0.7.2.1.
2. Keep your existing `config.lua` values.
3. Restart the `airops_weather` resource.

No configuration, database, API, SDK, or export migration is required.

## Fixed startup errors

```text
server/providers/openmeteo.lua: attempt to index a nil value (field 'Providers')
server/main.lua: attempt to index a nil value (field 'Validation')
```

The provider registry is now loaded before validation and concrete provider modules.
