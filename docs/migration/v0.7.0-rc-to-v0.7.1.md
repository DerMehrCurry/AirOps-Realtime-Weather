# Migration: v0.7.0-rc to v0.7.1

v0.7.1 is a stabilization patch without removed exports or SDK methods.

## Behavior changes

- Warning severities now use `INFO`, `YELLOW`, `ORANGE`, and `RED`.
- `GetJSONPretty()` now returns genuinely formatted JSON.
- `jsonUpdated` is emitted only when substantive data changes. Volatile timestamps do not trigger an update by themselves.
- Zone integration events are emitted once instead of twice.
- Shutdown webhooks bypass the retry queue because the resource is already stopping.

Existing calls without a zone continue to resolve to `default`.
